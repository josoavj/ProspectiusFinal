Guide utilisateur et développeur

Démarrage rapide

Prospectius est un CRM desktop qui conserve les données sur votre base MariaDB ou MySQL.

Pour les utilisateurs

1. Télécharger

Téléchargez l’archive correspondant à Windows ou Linux depuis la page Télécharger. Sous Linux, exécutez le binaire contenu dans le dossier bundle.

2. Préparer MariaDB

Installez MariaDB sur votre ordinateur ou serveur, puis conservez l’hôte, le port, l’utilisateur et le mot de passe nécessaires à la connexion.

3. Connecter l’application

Au premier lancement, renseignez la configuration de la base. Prospectius initialise ensuite le schéma et vous permet de créer le premier administrateur.

Fonctions à découvrir

  • Assistant de création de prospect en plusieurs étapes.
  • Pipeline Kanban et historique des interactions.
  • Gestion des utilisateurs et des rôles administrateur, commercial et utilisateur.
  • Sauvegarde SQL complète depuis les paramètres.

Développeurs

git clone https://github.com/josoavj/ProspectiusFinal.git
cd ProspectiusFinal
flutter pub get
flutter run -d linux

Pour Windows, remplacez la dernière commande par flutter run -d windows. Consultez l’architecture technique avant d’ajouter une fonctionnalité.
