Guide d’installation

Préparer votre environnement

L’application nécessite une base MariaDB ou une installation MySQL compatible, ainsi qu’un poste Windows ou Linux.

Installer MariaDB

Windows

Téléchargez MariaDB depuis mariadb.org, suivez l’assistant et conservez le mot de passe administrateur.

Linux

sudo apt update
sudo apt install mariadb-server
sudo systemctl enable --now mariadb

Initialiser la base

Les releases contiennent le dossier Database avec les scripts SQL. Vous pouvez importer le schéma avec :

mysql -u root -p < Database/Prospectius.sql

L’application peut également préparer le schéma lors de la première connexion selon les droits du compte utilisé.

Configurer Prospectius

  1. Lancez l’application.
  2. Indiquez l’hôte, le port 3306, l’utilisateur, le mot de passe et la base.
  3. Testez la connexion puis enregistrez la configuration.

Développement

flutter pub get
flutter run -d windows
flutter run -d linux

Pour supprimer le schéma de test, utilisez uniquement Database/SuppressionDB.sql après avoir effectué une sauvegarde.
