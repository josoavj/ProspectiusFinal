Politique de sécurité

La sécurité de Prospectius

Prospectius privilégie la souveraineté des données : la base est choisie et administrée par l’organisation qui déploie l’application.

Mesures intégrées

  • Hachage BCrypt des mots de passe et codes de récupération.
  • Stockage sécurisé du mot de passe de base lorsque la plateforme le permet.
  • Contrôle des rôles et confirmation des opérations administratives sensibles.
  • Transactions, verrous et gestion des conflits pour les opérations critiques.
  • Outils de sauvegarde SQL et scripts de restauration de l’environnement.

Recommandations

  • N’exposez pas directement le port MySQL sur Internet ; utilisez un réseau privé ou un VPN.
  • Utilisez des mots de passe uniques et un compte SQL aux privilèges minimaux.
  • Maintenez le système, MariaDB et Prospectius à jour.
  • Protégez les sauvegardes et les codes de récupération hors de l’application.

Signaler une vulnérabilité

Ne publiez pas une faille non corrigée. Envoyez une description reproductible, l’impact, les versions concernées et, si possible, une proposition de correction à josoavonjiniaina13@gmail.com.

Évitez d’inclure des mots de passe, données personnelles ou copies de bases réelles dans votre signalement.
